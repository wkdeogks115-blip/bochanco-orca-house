# 운영 모델

## ChatGPT Work — Manager Runtime
정책, 판단, Context, Risk, Budget, Evidence Gate, Next Action을 관리한다.

## ORCA — Execution Runtime
Run / Task / Dispatch / Worktree / Terminal / Worker lifecycle을 실행한다.

## Codex — Code Specialist
코드 수정, shell, 테스트, diff, PR 작업을 담당한다.

## SOURCE_MAP — Evidence Provenance
Source → Claim → Pattern → Decision → Artifact → Eval 계보를 보존한다.

## GitHub — Durable State
코드와 검증 가능한 텍스트 상태를 영구 보존한다. Chat/Work 기억만을 SSOT로 사용하지 않는다.
