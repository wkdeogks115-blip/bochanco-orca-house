# 패치 종료선 / Stop Lines

## SOURCE_MAP
외부 independent review 전 패치/Freeze 금지.
외부 결과는 ACCEPT / MATERIAL_PATCH / HOLD / REDESIGN으로 평가한다.
ACCEPT 후 Freeze 후보. 단순 개선 아이디어로 재패치하지 않는다.

## Runtime
R1: `orca orchestration run-current --json` read-only stable-pane Gate.
R1 PASS 후에만 R2.
R2: Run 1 / Task 1 / Worker 1 bounded smoke.
R2 PASS 후 `FROZEN_FOR_V1_RUNTIME_BASELINE` 판단.
R1/R2 각각 correctness Material Issue에 한해 최소 수정 cycle을 허용한다.

## Factory B
001 = ACCEPT/CLOSED. Material trigger 없이 002 자동 생성 금지.

## Reopen 조건
- 재현 가능한 correctness bug
- security/privacy/credential issue
- portability regression
- data/state corruption
- upstream contract 파손
- Frozen architecture로 필수 요구사항 구현 불가능
- 외부 evidence가 기존 판단을 실질적으로 뒤집음
